## Implementation Tasks

### 1. CSS — Add Light Theme Variables & Body Styles
**File:** `assets/css/styles.css`
- Add `[data-theme="light"]` selector with light theme variables
- Update `body` to use `var(--bg)`, `var(--text)`, etc.
- Replace hardcoded colors in gradients/backgrounds with variables
- Ensure all components use theme variables

### 2. HTML — Add Floating Toggle Button
**File:** `index.html`
- Add toggle button in `<body>` (before scripts):
  ```html
  <button id="themeToggle" class="theme-toggle" aria-label="Toggle theme" title="Toggle light/dark mode">
    <svg class="icon-sun" ...></svg>
    <svg class="icon-moon" ...></svg>
  </button>
  ```

### 3. CSS — Style Floating Toggle
**File:** `assets/css/styles.css`
- Fixed position (bottom-right or top-right)
- Animated sun/moon icon swap
- Hover/focus states
- Respects current theme

### 4. JS — Theme Toggle Logic
**File:** `assets/js/main.js`
- Detect system preference: `window.matchMedia('(prefers-color-scheme: dark)')`
- Read saved preference from localStorage
- Apply theme on load (before paint to avoid flash)
- Toggle function: switch theme, save to localStorage, update DOM
- Listen for system preference changes (optional)

### 5. CSS — Fix Nav Bar Visibility
**File:** `assets/css/styles.css`
- Strengthen header/nav background so it doesn't disappear on scroll
- Use `var(--surface)` or `var(--card)` with backdrop-filter
